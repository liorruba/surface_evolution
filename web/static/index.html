REGOLIT

REworking and Gardening Of Lunar Impacted Terrains: a Monte Carlo model of cratering, ejecta and regolith gardening with a layered subsurface.

Initial subsurface layers Rows are bottom-up within a class: the first row of a class is the deepest layer, the last row is the surface. The model uses class 1 for the whole grid when it exists, otherwise class 0. Fractions are normalized.

    Results

    Set the parameters and press Run model. Runs with the default parameters take about a second; large grids or long durations take longer. Results are kept on the server for a while and can be shared with the page link.

    Run

    The model follows Richardson et al. (2009) and adds an efficient layered description of the subsurface. Source and documentation: the surface_evolution repository. Maps are indexed with x to the right and y upward; the domain is periodic.
